# User Management & Role Assignment Guide

This guide explains the procedure for onboarding new users and managing their roles (Editor, Scheduler, Admin) within the Brand Manager Application.

## 1. User Registration (Onboarding)
**Procedure:**
1.  **Direct the User to Sign Up**: Share the application URL with the new team member.
2.  **Sign Up Page**: The user clicks "Sign Up" and enters their:
    -   Full Name
    -   Email Address
    -   Password
3.  **Default Role**: Upon successful registration, the system **automatically assigns the 'Editor' role** to the new account.
4.  **Immediate Access**: The user is immediately logged in and redirected to the "My Tasks" page.

## 2. Assigning Roles (Admin Only)
Since all new users start as "Editors" by default, an Admin must manually upgrade them to "Scheduler" or "Admin" roles if needed.

**Procedure:**
1.  **Log in as Admin**: Sign in with an account that has 'Admin' privileges.
2.  **Navigate to Admin Panel**: Click on the **Admin** (Settings icon) in the sidebar.
3.  **Locate "User Management" Section**: Scroll down to the User Management area. This section lists all registered users.
4.  **Find the User**: Use the search bar to find the new user by name or email.
5.  **Change Role**:
    -   Locate the "Role" dropdown menu next to their name.
    -   Select the desired role (e.g., **Scheduler**, **Admin**, **Marketing**, **Auditor**).
    -   The system will automatically save the change and show a success message.
    -   *Note: The user may need to refresh their page or re-login to see the new features.*

## 3. Role Capabilities
-   **Editor** (Default): Can view assigned tasks, update status, and submit social media links. Restricted from scheduling or deleting tasks.
-   **Scheduler**: Can create new tasks, assign them to editors, and view task history.
-   **Admin**: Full access to all features, including deleting tasks/users, managing lists (brands/programs), and viewing all data.
-   **Marketing / Auditor**: View-only dashboards for specific reporting needs.

## Summary for Client
> "Simply ask your new staff to sign up on the app. They will automatically become Editors. Then, one of your Admins can log in, go to the Settings page, and switch their role to 'Scheduler' or 'Admin' if required."
